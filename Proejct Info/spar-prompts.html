How to use these prompts

1
Copy the Master Context below and paste it as the very first message into a new conversation with each LLM. This gives every model the same understanding of what SPAR is and what the debate is about.
2
Immediately follow the Master Context with the Agent-Specific System Prompt for that LLM — same conversation, next message. Do not start a new conversation between these two.
3
Then paste the Round 1 Trigger (at the bottom of each agent section) to start the debate. The LLM will respond with its Round 1 JSON output.
4
For Round 2, collect all five Round 1 JSON outputs, then paste them together into each agent's conversation followed by the Round 2 prompt (which you will find in the proposal document, Section 5.2.3). The Claude Devil's Advocate session must be kept completely separate from the Claude Political agent session — open two browser tabs.
5
Temperature setting: set to 0 (or minimum available) in every LLM for reproducibility. In ChatGPT: not directly settable via UI — use the API. In Claude: use the API with temperature=0. In Gemini: temperature=0 in Google AI Studio.
